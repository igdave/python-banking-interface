# 🏦 Python Banking Interface

A lightweight, object-oriented Python application that models a banking ledger — built as a foundation project to practice clean OOP design, defensive programming, and real-time transaction tracking.

---

## 📌 What It Does

- Creates and manages bank accounts via Python classes
- Tracks deposits, withdrawals, and transaction history
- Validates all inputs using defensive programming techniques
- Logs transactions in real-time with dynamic state updates

---

## 🚀 How to Run

**Requirements:** Python 3.x (no external libraries needed)

```bash
# Clone the repo
git clone https://github.com/igdave/python-banking-interface.git

# Navigate into the folder
cd python-banking-interface

# Run the application
python "banking ledger.py"
```
